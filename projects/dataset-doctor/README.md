# dataset-doctor

**Audit and clean JSONL datasets before fine-tuning or evaluation.** Duplicates, PII, junk
and train/test contamination, in one command, with no dependencies.

```bash
python3 doctor.py audit data/sample_train.jsonl --test data/sample_test.jsonl
python3 doctor.py clean data/sample_train.jsonl -o clean.jsonl --dedupe --redact --drop-short
```

## Checks

| Check | Method |
|---|---|
| Exact duplicates | hash of normalized text (case, accents, spacing) |
| Near duplicates | MinHash (128 permutations) + LSH, **confirmed by exact Jaccard** on word 5-shingles, so no false pairs are reported |
| PII | e-mail, phone (BR/intl), IPv4, and **checksum-validated** CPF, CNPJ and credit cards (Luhn) |
| Junk | too short, length outliers (Q3 + 3·IQR) |
| Contamination | 13-gram overlap (as in the GPT-3 paper), attributing each test item to the train item with the **most** shared n-grams |

Understands chat format (`{"messages": [...]}`) or any fields via `--fields prompt,completion`.
`--min-health 90` turns it into a CI gate.

## Validation

The sample dataset is generated by `data/make_sample.py` with **planted** issues recorded in
`data/planted.json`, including decoys that must not be flagged (an invalid CPF, version
numbers). The tests require the audit to find exactly the planted set: no misses, no false alarms.

## A finding along the way

The first version attributed contamination to the *first* train item sharing a 13-gram. On
templated data, every item shares boilerplate, so it named the wrong source (#0 instead of
#10). Attribution now uses the item with the most shared n-grams and reports the overlap
fraction, which also separates copied items (~90%+) from shared templates.
