# Jogo Bobo

Um jogo simples em HTML onde voce clica no botao para ganhar pontos. O botao se move para uma posicao aleatoria apos cada clique.

## Como jogar

1. Abra o arquivo `index.html` em um navegador.
2. Clique no botao "Clique!" sempre que ele aparecer para aumentar sua pontuacao.

Divirta-se!
